- **Figure job:** `47860baa23dd4f339fb1275c259607b5`
- **Saved run:** `0cca98bd889e49dd89b3993a6407bff5`
- **Run context:** audited multi-theme G1 retrieval evaluation; 26 themes, 201 queries.
- **Review scope:** visual design and rendering of all 18 PNGs in the app-generated bundle. PNGs were the primary review view; corresponding PDF/SVG exports are present. No figures, manifests, evaluation data, or code were changed.

## Overall publication readiness

The set has a coherent Portuguese academic style, useful titles/subtitles, generally good contrast, and appropriate visual forms for most comparisons. Theme-level uncertainty and sample context are often stated. It is **not yet consistently publication-ready**: the formulation heatmap annotations collide, all three paired-delta figures have adjacent x-axis labels running together, and uncertainty shading obscures several multi-series cutoff plots. These should be addressed through reusable layout/encoding behavior in the shared generator. Several figures would also benefit from concise captions or legend clarification. No underlying calculations were audited in this visual review.

Severity: **High** = blocks reliable reading at the rendered size; **Medium** = materially reduces clarity or paper-size legibility; **Low** = polish/annotation improvement.

## Figure findings

### `headline_summary.png`

- **Severity: Low.** The four-card layout is clean and readable, but the cost card contains only “Temps indisponíveis.” and leaves a large panel largely empty. This weakens visual balance and provides little analytical value.
- **Improvement:** When the field is unavailable, use a compact unavailable-data treatment or omit the card; retain the explicit distinction between ranking computation and total latency whenever a time value is shown.
- **Scope:** General pipeline behavior for missing metrics; the empty-card effect is especially pronounced in this layout.

### `fig01_evaluation_composition.png`

- **Severity: Medium.** The binary theme-by-formulation matrix is legible at full size, but long rotated column labels and the 26-row list will become small at column width. The continuous-looking colorbar is redundant for a binary/count matrix, and the meaning of each annotated `0`/`1` is not stated in the panel.
- **Improvement:** State that cells count queries, use a binary legend or direct count key instead of a continuous colorbar, and offer wrapped/short labels or a full-width preset.
- **Scope:** General heatmap/label layout; the 26 themes and long formulation labels are data-shape contributors.

### `fig02_retrieval_coverage_and_ceiling.png`

- **Severity: Medium.** Query-level scatterplots suit the observations and the `n` labels are helpful. Repeated discrete values stack into dense vertical bands, particularly at the upper end, obscuring point counts; diagonal formulation labels also consume substantial space.
- **Improvement:** Add subtle deterministic horizontal jitter or use a compact strip/swarm treatment, preserve visible per-formulation `n`, and consider wrapped labels. Keep the two metrics in separate panels as currently done.
- **Scope:** General overplotting behavior for discrete query metrics; repeated values are intrinsic to the data shape.

### `fig03_ranking_quality_leaderboard.png`

- **Severity: Medium.** The three aligned dot-and-interval panels are an appropriate summary and are readable. However, the vertical dashed reference is unexplained, and colors/markers do not have a legend; direct row labels help but do not explain the visual grouping. “Zoom” is stated, but readers could still overread small point differences.
- **Improvement:** Explain or directly label the reference line, include a compact encoding key or use a consistent method-family convention, and state that intervals are descriptive theme-bootstrap intervals in the caption.
- **Scope:** General annotation/legend issue in the ranking-summary family.

### `fig04_method_by_formulation.png`

- **Severity: High.** Numeric cell annotations visibly collide and are clipped across all three heatmaps (notably F1@20 and MRR@20). Several values run together, compromising exact reading. Long row/column labels are also crowded, and no per-formulation sample count is shown despite one singleton category.
- **Improvement:** Remove cell text from the main figure or substantially enlarge cells/reduce annotation precision; wrap or shorten labels; show `n` per formulation and visually flag singleton groups. Keep numerical values in the accompanying table/CSV.
- **Scope:** General annotation-density/layout problem, amplified by the number and length of categories in this dataset.

### `fig05_paired_deltas_vs_cross_encoder.png`

- **Scope:** General multi-panel spacing and repeated-label issue in the shared paired-delta template.
